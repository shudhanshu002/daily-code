How It Works: The Data Structure

The core of this project is a Markov Chain, which is a type of directed graph.
1. Analysis (Building the Graph): We analyze a source melody to find the probability of which note will follow any given note. For example, after 'C4', 'G4' might appear 70% of the time and 'F4' 30% of the time. This creates our graph nodes (notes) and weighted edges (probabilities).
2. Generation (Traversing the Graph): We pick a random starting note. Then, we "walk" the graph by choosing the next note based on the probabilities, creating a new, statistically similar melody.
